# Asset provenance

Velmont uses original procedural canvas artwork, generated WebP illustrations, bundled fonts with their license notices, and procedural Web Audio effects. Runtime assets live under `public/art`, `public/brand`, `public/cinematics`, and `public/fonts`.

Opening narration and audio credits are documented in [the intro audio credits](next-preview/intro-v3/AUDIO-CREDITS.md). Preserve these credits and the font license files. No runtime LLM dependency is required.

Earlier Sensor Fusion city imagery and Last Lift renderer descriptions belong to retired prototypes; their source is available in Git history.
