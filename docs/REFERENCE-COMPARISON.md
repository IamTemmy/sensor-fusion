# Reference observations and testable goals — October 15, 2026

Inspected the visible landing/rules interfaces of Handshake's supplied examples in a browser. Did not complete multiplayer sessions, so do not claim superiority over their gameplay.

- Treasure Bluff: https://treasure-bluff-joel-pinto.joelpinto.chatgpt.site/ — 2–6 players; eight simultaneous Collect/Steal rounds; three concise rule steps. Its visible instructions say to create a new room if someone leaves mid-game. Strength: immediately understandable social dilemma.
- Panic Protocol: https://panic-protocol.victory-1001.chatgpt.site/ — 2–8 operators; different panels, instructions for other operators, three escalating rounds. Landing also exposes global rankings, goals/rewards, profile and open room directory. Strength: immediately clear shared pressure and consistent visual language. Actual end-to-end reliability and fun were not tested.
- Keep Talking and Nobody Explodes: https://keeptalkinggame.com/ — official description centers communication, asymmetric information and a shared timer. Inspiration principle only; no content, art, manuals or code reused.
- Spaceteam: https://www.sleepingbeastgames.com/ — official developer describes cooperative shouting on phones/tablets. Inspiration principle only; no assets/code reused.

Our intended differences: Sensor Fusion makes the same street look different through different sensors and carries consequences across a route; Blackout combines public promises/private prices with future capacity consequences and a common failure condition. Both have explicit solo-with-bots onboarding, role/strategy replay, reactive illustrated environments, recovery and bounded advancement.

## Evidence required before saying more interesting
Play each game with the same 3–4 people, rotating order. Record time to first meaningful decision, onboarding questions, abandoned sessions, voluntary rematch votes, distinct strategies attempted, and post-session preference/reasons. Do not treat automated tests or more features as proof of preference. Target: no facilitator needed, all players make useful decisions, at least one spontaneous negotiation/coordination moment per round, and voluntary rematches. Compare only observed results; report small sample sizes honestly.
