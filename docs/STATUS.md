# Initial vertical slice

Implemented: server-authoritative rounds; role-specific view projection; room codes; bearer seat tokens saved in sessionStorage; revision-based compare-and-swap writes; deadline resolution; bots; responsive UI; public evidence/pledges for remote communication.

Transport: 1.2-second polling. This is near-real-time and does NOT satisfy the proposed 300ms synchronization target. Polling is an initial hosted slice decision, not a claim that WebSockets are implemented.

Known limitations: no independent host migration; no room-level/global creation rate limit; join/input abuse protections incomplete; static schematic sensor visuals rather than scenario-specific animation; no real-device playtest yet. Refresh recovers the seat within the same browser tab. Closing the tab may clear sessionStorage. Educational scenarios and economics require source review. No contest submission has occurred.

Blackout scope: three abstract thermal plant archetypes; six rounds; public promises, private bids, explicit emergency settlement. No solar/storage, bilateral deals, or regulator fines yet. Spite prevention is not solved.

Sensor Fusion scope: six authored observational puzzles, evidence sharing, collective decisions, full debrief. Bots share their assigned observations; human votes determine decisions.
